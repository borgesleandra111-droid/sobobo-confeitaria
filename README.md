# Sobobo Confeiteira — Landing Page

Landing Page responsiva criada para a Sobobo Confeiteira, negócio de bolos e doces por encomenda, como desafio do curso.

## 🌐 Site publicado

https://borgesleandra111-droid.github.io/sobobo-confeitaria/

## 📦 Repositório

https://github.com/borgesleandra111-droid/sobobo-confeitaria

## 🛠️ Tecnologias utilizadas

- HTML5 semântico
- CSS3 (arquivo externo, sem estilos inline e sem `<style>` no HTML)
- Git e GitHub para versionamento
- GitHub Pages para publicação
- Fontes Google Fonts: Fraunces (títulos) e Karla (texto)

## 📁 Estrutura do projeto

```
├── index.html
├── css/
│   └── style.css

└── README.md
```

## ✨ Sobre o projeto

A página apresenta a Sobobo Confeiteira: uma seção inicial (hero) com chamada para encomenda, uma seção sobre o negócio, os produtos oferecidos (bolos personalizados, docinhos gourmet e kits de festa), uma galeria de fotos de doces já produzidos e uma seção de contato. O layout é responsivo, funcionando em celular, tablet e desktop, e segue boas práticas de acessibilidade (texto alternativo descritivo nas imagens e hierarquia correta de títulos).

## 🤖 Uso consciente de IA

A Claude (Anthropic) foi utilizada como apoio durante o desenvolvimento deste projeto, nas seguintes etapas:

- Estruturação do HTML semântico (header, main, section, article, footer) a partir dos requisitos do desafio.
- Definição da paleta de cores (tons pastel de rosa e lilás) e da combinação tipográfica do projeto.
- Escrita do CSS externo responsivo, incluindo o menu mobile feito apenas com HTML/CSS (sem JavaScript).
- docs: adiciona links do site e do repositório
- Redação dos textos de cada seção da página.
- Organização e compressão das imagens usadas na galeria.

Todo o código foi revisado antes da entrega para garantir que atende aos critérios do desafio.
